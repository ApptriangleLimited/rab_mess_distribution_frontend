# Mess Distribution Frontend

Next.js 16 App Router prototype for RAB mess distribution roles (CC, Daily, Mess, Consume, Ration).

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo

See [../docs/DEMO.md](../docs/DEMO.md) for the full walkthrough.

## Stack

- Next.js 16 · React 19 · Tailwind CSS v4 · TypeScript
- localStorage mock store (no backend)
- i18n: `src/i18n/messages/en.ts` (+ `bn.ts`)

## Scripts

```bash
npm run dev
npm run build
npm run start
npm run lint
```
