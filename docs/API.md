# API

Base URL: `{API}/api/v1`  
Envelope (existing frontend contract — do not break):

```json
{ "ok": true, "success": true, "message": "", "data": {} }
```

Error:

```json
{ "ok": false, "success": false, "message": "...", "code": "ERROR", "detail": "...", "errors": [] }
```

Interactive docs: `/docs` (disabled when `APP_ENV=production`).

## Authentication

`Authorization: Bearer <access_token>`

| Method | Path | Who |
| ------ | ---- | --- |
| POST | `/api/v1/auth/login` | public (returns access + refresh) |
| POST | `/api/v1/auth/refresh` | public (rotates refresh; reuse revoked) |
| POST | `/api/v1/auth/logout` | staff (denies access + refresh family) |
| GET | `/api/v1/auth/me` | staff |
| GET | `/api/v1/auth/permissions` | staff |
| POST | `/api/v1/auth/forgot-password` | public (generic response) |
| POST | `/api/v1/auth/reset-password` | public |
| POST | `/api/v1/auth/mfa/*` | staff |

Roles: `cc`, `daily`, `mess`, `consume`, `ration`, `admin`. Backend also seeds `role_permissions` and enforces `require_permission` on snapshot/files/notifications. Frontend hiding buttons is not sufficient.

Auth is `Authorization: Bearer`. JWT is not stored in a cookie, so classic cookie CSRF does not apply to API writes. The `mess_session` cookie is a UI role hint only.

## Pagination

List endpoints that paginate (`members`, `tag-requests`) use `page`, `page_size` (max 500 on tag-requests). Tighten to 100 in a later hardening pass.

## Important workflows

1. **CC creates member** → `pending` → Daily/CC `accept` (+ optional tag) → `approved`.
2. **CC requests tag** → Daily queue `requested` → Daily `accept` → `assignments` written for the date range → Consume/Ration letters use those days.
3. **Daily paints FR/CD** → Ration queue; other duty tags → Consume queue.
4. **Pritibhoj** → user-entered sheets via `/api/v1/pritibhoj`.
5. **Snapshot** `GET /api/v1/app/snapshot` hydrates the SPA. `PUT` applies only the calling desk's allowed keys (`docs/CATALOGS.md`). `POST /api/v1/app/import` is admin-only.
6. **Catalog** `GET/PUT /api/v1/catalog` for Settings ranks/wings/forces/banks.
7. **Files** `POST /api/v1/files` + authenticated download. Paths are generated keys, never client paths.
8. **Notifications** list / unread-count / read — no new inbox UI; existing toasts stay.

## Reports

- `GET /api/v1/reports/consume/{YYYY-MM}`
- `GET /api/v1/reports/ration/{YYYY-MM}`
- `GET /api/v1/reports/manpower?day=YYYY-MM-DD`

Official letter layout and FR-fuel rules remain in `src/lib/reports.ts` so printed amounts stay identical. Those builders read snapshot-hydrated store data.
